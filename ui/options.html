FilterHub help

What is FilterHub?
FilterHub is a centralized blocklist repository: 44 lists from trusted sources (EasyList, AdGuard, uBlock Origin, HaGezi, Phishing Army, Fanboy, DuckDuckGo and others), about 3.4 million rules in total.

Protection levels
Light — 7 lists, ~261K rules, fastest. Medium — 17 lists, ~718K rules, the recommended balance of protection and speed. Maximum — all 44 lists, ~3.9M rules, for powerful PCs only.

Can I enable everything at once?
It is not recommended: lists overlap, and the big ones (HaGezi TIF — 43 MB, DuckDuckGo US Maximum — 30 MB) slow the browser down. Pick one main ad list, one privacy list, then extras as needed.

Warnings
Google Ultra Strict may break reCAPTCHA and Google fonts. OISD Full and HaGezi Pro Plus are heavy. Lists marked with a warning badge deserve caution.

Categories
Ad blocking — main ad filters. Privacy — trackers and data collection. Security — phishing, malware, coin-mining. Annoyances — cookie banners, popups, widgets. Regional — language-specific lists. Pro — maximum-strength lists.

License
FilterHub is distributed under Apache License 2.0; individual lists keep their upstream licenses. Full documentation: FilterHub/Doc on GitHub.

Recommendations

Security

Privacy and security protection settings while browsing sites.

Clean tracking URLs
Remove tracking parameters (utm_*, fbclid, gclid, etc.) and unwrap redirect links
Sanitize URL
Warnings about punycode domains (phishing) and credentials in URLs
WebRTC IP leak protection
Blocks WebRTC leaks (disabled if the site is granted geolocation permission)
Fingerprinting protection
Adds noise to Canvas, spoofs navigator.userAgent and platform
Audio fingerprint protection
Adds inaudible micro-noise to Web Audio data reads (silent tones used for tracking, e.g. on AliExpress). Does not affect playback
Fingerprint shield
Always-on value noise: Canvas, CPU/RAM values, Battery API, sendBeacon, media devices, screen depth, local font list. Does not change your User-Agent
Spectre side-channel protection
Coarsens timer precision (performance.now to 1 ms) and disables SharedArrayBuffer — the toolkit for timing side-channel attacks
DNS rebinding protection
Blocks sites that resolve to local/private addresses — attacks on your router and home devices. Paused while a proxy/Tor is active
Ask for local network access
Sites must ask before their scripts contact devices on your local network (router, IoT). Local pages are unaffected
Cross-origin isolation (COOP/COEP)
Opt-in: enables SharedArrayBuffer for sites that need it (multithreaded WASM) via cross-origin isolation. May break cross-origin images on some sites
localStorage quota (5 MB per site)
Cap per-site localStorage — stops quota-filling trackers and storage bloat
Confirm every download
Ask before saving a file — protects against hidden drive-by downloads
Block media autoplay
Video and audio start only on click
Site isolation
Separate cookie and localStorage storage for each domain
HTTPS only
Automatically redirect HTTP to HTTPS
Clear cookies on exit
Delete all cookies (incl. container tabs) when the browser closes
Clear cache on exit
Wipe the HTTP cache when the browser closes — kills ETag and cache-based cross-session tracking

Letterboxing
Round window dimensions to reduce fingerprinting via screen size
Auto-decline cookie banners
Automatically click "Reject / Decline / Reject all" on cookie consent dialogs and hide them
Super Drag
Drag selected text to search it in a background tab, drag a link to open it in background, drag an image for reverse image search
Fake media responses
