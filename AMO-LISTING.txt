The complete privacy stack of StartPOZI Browser, now in your Firefox.

★ AD & TRACKER BLOCKER
14 curated FilterHub lists (EasyList, EasyPrivacy, the uBlock core,
Peter Lowe, NoCoin, OISD, URLhaus) with Light / Medium / Maximum
presets and custom filters in EasyList format. A built-in offline base
of 113,000 rules starts blocking immediately — before a single list
has been downloaded.

★ COOKIE BANNERS REJECTED AUTOMATICALLY
About 70 CMP providers, shadow DOM support, multilingual heuristics.
Banners are dismissed without ever clicking "Accept".

★ URL TRACKING CLEANUP
utm_*, fbclid, gclid, msclkid and dozens of other tracking parameters
are stripped both at the network level and in the visible address.

★ DNT + GLOBAL PRIVACY CONTROL
DNT and Sec-GPC: 1 headers on every request, plus
navigator.globalPrivacyControl — the complete GPC opt-out.

★ ANTI-FINGERPRINTING
Canvas noise, WebGL masking, audio farbling, WebRTC IP-leak blocking,
media-device and font masking — ported straight from StartPOZI Browser.

★ MORE
Third-party cookie stripping · referrer trimmed to origin ·
<a ping>/beacon blocking · element zapper ("Block ads manually") ·
per-site protection toggle · a shield popup with live stats ·
settings styled after the browser, with the Bing picture of the day.
StartPOZI becomes your default search engine.

PRIVACY
No telemetry, no analytics, nothing sent anywhere. All data stays in
your browser. External requests are limited to filter-list updates
(GitHub), the daily background picture, and startpozi.com search.

Open source (GPL-3.0): github.com/StartPOZI/startpozi-privacy-extension

This add-on is a port of the privacy stack from our open-source
browser (github.com/StartPOZI/StartPOZI-Desktop-Browser, GPL-3.0).
Source code of the add-on: github.com/StartPOZI/startpozi-privacy-extension

PERMISSIONS AND WHY THEY ARE NEEDED
• webRequest + webRequestBlocking — the core of the add-on: request
  blocking and header injection (DNT, Sec-GPC, Referrer trimming),
  identical to the browser's behavior.
• host_permissions <all_urls> — the blocker must inspect requests to
  every site the user visits; no data is sent anywhere.
• scripting + content_scripts — injecting the cookie-banner rejections,
  anti-fingerprinting protections and the element picker.
• storage — settings, cached filter lists and session statistics are
  stored locally (storage.sync for settings, storage.local for lists,
  storage.session for stats). Nothing leaves the browser.
• tabs — per-tab blocked counters, the toolbar badge and reload after
  toggling protection for a site.
• cookies — shows the cookie count for the current site in the popup.
• browsingData — the optional "clear cookies/cache on exit" setting.
• alarms — filter-list refresh every 12 hours.
• webNavigation — resets per-page stats on navigation.
• chrome_settings_overrides (search_provider) — registers
  startpozi.com search; users can change it in Firefox settings.

DATA COLLECTION
None. The add-on collects no technical, interaction or personal data.
It makes no requests that carry user identifiers. The only external
requests are: (1) public filter lists from raw.githubusercontent.com,
(2) the daily background image metadata from bing.com, (3) startpozi.com
search — only when the user searches. Extension-page CSP forbids all
remote code (script-src 'self').

HOW TO TEST
1. Install, a welcome page opens.
2. Open any site with ads/trackers — the popup (toolbar icon) shows a
   live blocked counter; the badge appears on the icon.
3. Settings page: toggles (DNT, GPC, URL cleaning, fingerprint shield)
   take effect immediately; the blocker section lists FilterHub lists.
4. In the URL bar type "spz <query>" or set StartPOZI as the search
   engine — search goes to startpozi.com/search.html.

No test accounts are required — no feature depends on external logins.
